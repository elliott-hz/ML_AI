# AI Knowledge Learning System 🎓

An interactive learning platform for AI knowledge with dynamic visualizations, model training demos, and comprehensive lecture materials.

## 📋 Overview

This repository contains two main parts:

1. **Knowledge Base** - Markdown documentation and lecture slides organized by AI topics
2. **Code Base** - Interactive web application (React + FastAPI) for dynamic visualization and model training demonstrations

```

## 🚀 Features

### Knowledge Base
- **Structured Learning Modules**: Organized by topic (Mathematics, Deep Learning, Machine Learning)
- **Interactive Visualizations**: Dynamic 2D/3D plots for mathematical concepts
- **Model Training Demos**: Real-time training, validation, and testing with parameter adjustment
- **Lecture Slides**: Professional PPTX presentations for each topic

### Web Application
- **Dynamic Menu System**: Two-level navigation (Module → Topic)
- **Real-time Visualization**: 
  - Math topics: Interactive 2D/3D graphs (derivatives, gradients, surfaces)
  - Model topics: Live training monitoring, confusion matrices, metrics charts
- **Parameter Tuning**: Adjust hyperparameters and retrain models on-the-fly
- **Results Display**: Classification reports, accuracy curves, performance metrics

## 🚀 Quick Start (Recommended)

The easiest way to get started:

```bash
# First time setup and start all services
./dev.sh

# Or use the main startup script
./start.sh --install
```

After initial setup, for daily development:

```bash
# Start both frontend and backend
./start.sh

# Start only frontend
./start.sh --frontend-only

# Start only backend
./start.sh --backend-only

./stop.sh

## 📦 Installation

### Prerequisites
- Node.js >= 18.x
- Python >= 3.9
- CUDA-compatible GPU (for model training)

### Backend Setup

```bash
cd code-base/backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On macOS/Linux
# or
venv\Scripts\activate     # On Windows

# Install dependencies
pip install -r requirements.txt

# Run the server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Frontend Setup

```bash
cd code-base/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

### Generate Visualization Images

```bash
# Generate all mathematical visualization images
python scripts/generate_all_images.py

# Or generate specific module images
python code-base/experiments/math_visualization/derivative_demo.py
```

## 🔧 Available Scripts

### `start.sh`
Main startup script with options:
```bash
./start.sh                    # Start both services
./start.sh --frontend-only    # Start only frontend
./start.sh --backend-only     # Start only backend
./start.sh --install          # Install dependencies and start
./start.sh --help             # Show help
```

Features:
- ✅ Prerequisites checking
- ✅ Automatic dependency installation (with `--install`)
- ✅ Colored output for better readability
- ✅ Graceful shutdown on Ctrl+C
- ✅ Process management

### `stop.sh`
Stop all running services:
```bash
./stop.sh
```

### `dev.sh`
Quick development start (installs deps and starts):
```bash
./dev.sh
```

## 🎯 Usage Examples

### Example 1: Exploring Derivative Visualization

1. Navigate to `Mathematics → Advanced Math` in the web app
2. View the interactive 2D/3D derivative plot
3. Adjust parameters to see how derivatives change

### Example 2: Training AlexNet Model

1. Navigate to `Deep Learning → AlexNet`
2. Configure training parameters (learning rate, batch size, epochs)
3. Click "Start Training"
4. Monitor real-time loss curves and accuracy metrics
5. View confusion matrix and classification report after training

## 🔧 Development

### Adding a New Knowledge Module

1. Create Markdown file in `knowledge-base/modules/[category]/`
2. Add corresponding slide in `knowledge-base/slides/[category]/`
3. Create experiment script in `code-base/experiments/`
4. Generate visualization images to `generated-images/`
5. Update menu configuration in frontend

### API Endpoints

```
GET  /api/knowledge/{module}/{topic}     # Get knowledge content
GET  /api/slides/{topic}                 # Get slide file path
POST /api/experiments/train              # Start training task
GET  /api/experiments/status/{id}        # Check training status
WS   /ws/experiment/{experiment_id}      # Real-time training updates
GET  /api/visualizations/{topic}/{name}  # Get visualization image
```
